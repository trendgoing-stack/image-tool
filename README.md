# 画像かんたん変換

写真のサイズを小さくしたり、JPEG / PNG に変換したりできるWebアプリです。
SNSへの投稿やメールでの送信、フォームへのアップロードの前に、画像を軽くするのに便利です。

**▶ アプリを開く: https://trendgoing-stack.github.io/image-tool/**

登録やログインは不要です。無料で使えます。

## できること

- **リサイズ** — 「長辺を1920pxに」「幅と高さを指定」「50%に」などの方法で大きさを変えられます。よく使うサイズ（1080 / 1280 / 1920 / 2560px）はワンタップで選べます
- **圧縮** — JPEGの画質を調整してファイルサイズを小さくします。「500KB以下に」のように目標サイズを指定すると、それに収まる最もきれいな画質を自動で探します
- **形式の変換** — JPEG と PNG に変換できます。透過のあるPNGをJPEGにするときは、背景色（白・黒・好きな色）を選べます
- **まとめて処理** — 複数の写真を一度に処理できます。処理の前後を見比べることもできます
- **保存** — 1枚ずつ保存するほか、まとめて写真アプリに保存したり、ZIPファイルにしてファイルアプリに保存したりできます
- **プリセット** — よく使う設定に名前を付けて保存しておけます

## iPhoneで使う

ホーム画面に追加すると、アプリのように全画面で使えます。一度開けば、電波のない場所でも起動します。

1. **Safari** で上のリンクを開く
2. 画面下の共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」をタップ

> [!IMPORTANT]
> Safariで開いた場合とホーム画面から開いた場合では、プリセットが**別々に保存**されます。
> ふだん使うほうで保存するようにしてください。

AndroidやPCでも、ChromeやEdgeなどのブラウザで同じように使えます。

## 画像とプライバシーについて

- 画像はすべて**お使いの端末の中だけ**で処理されます。インターネットには送信されないので、ほかの人に見られることはありません
- 位置情報などの**EXIF情報はすべて削除**されます。撮影場所を知られたくない写真を送る前にも使えます
- 写真アプリに保存すると撮影日時が失われるため、**保存した日の写真**として並びます
- **元の写真は削除されません**。不要になったら写真アプリで削除してください

## うまくいかないときは

- **大きな写真が小さくなった** — iPhoneのSafariには一度に扱える画像の大きさに上限（約1,677万画素）があるため、それを超える写真（iPhone標準の24MP・48MPなど）は自動で縮小されます
- **読み込めない画像がある** — ファイルアプリから選んだHEIC形式の画像は読み込めないことがあります。写真アプリから選ぶと自動でJPEGに変換されます
- **色が少し違う** — 出力はsRGBになるため、iPhoneで撮った鮮やかな写真は色がわずかに変わることがあります
- **新しい機能が出てこない** — 画面上部に「更新があります」と出たらタップしてください。画面のいちばん下でバージョンを確認できます

## 開発者向け

ビルド不要の静的サイトです（HTML / CSS / JavaScript のみ）。ZIPの作成に [fflate](https://github.com/101arrowz/fflate)（MITライセンス）を `vendor/` に同梱しています。

```bash
node scripts/serve.mjs        # http://localhost:8080/image-tool/ で確認
```

ファイルを変更して公開するときは、Service Worker のキャッシュを更新するためにバージョンを上げてください。キャッシュ対象の漏れもあわせて確認します。

```bash
node scripts/bump-version.mjs 0.3.1
```

アイコンは `node scripts/generate-icons.mjs` で生成します（デザイン元は `icons/icon.svg`）。実機での確認項目は [TESTING.md](TESTING.md) にあります。
